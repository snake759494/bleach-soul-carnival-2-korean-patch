# BLEACH 소울 카니발 2 (PSP) 한글패치 v1.3

일본판 『BLEACH ～ソウル・カーニバル2～』(UCJS10106)용 비공식 한국어 패치입니다.

## 적용
```
xdelta3 -d -s "Bleach - Soul Carnival 2 (Japan).iso" Soul_Carnival2_KR_v1.3.xdelta "Bleach - Soul Carnival 2 (Japan) [KR].iso"
```

EBOOT는 수정하지 않았습니다(데이터 파일 cfc.dig만 교체).

## 번역 범위
- 게임 내 텍스트 전체: 메시지 표 406개, 문자열 약 24,000개(고유 6,072개) — 스토리 대사, 튜토리얼, 메뉴, 상점·합성, 아이템·액세서리·소울 비즈 설명, 훈장 조건, 캐릭터·기술 이름, 보이스·BGM 목록, 통신 문구
- 이미지 90종(260곳): 메뉴·상점·기술개발국 스탯 라벨, 메뉴 사이드바·능력치 라벨·옵션, 월드맵, 스탬프 카드, 강화·합성 결과, 알람·타이머·애드혹 화면, 데미지 표시, 간판(쿠로사키 의원·우라하라 상점·카라쿠라 제일고등학교 등), 시바 쿠카쿠 현수막, 공사 표지판 등. 원본 라벨 스타일(광채·테두리·버튼·명판)에 맞춰 한글을 다시 그렸습니다.
- 아이콘 폰트의 희귀 한자(瀞·殛 등)는 번역문에서 한글로 풀어 쓰고, 전투 상성 배지(破·仮·死·虚)는 파·가·사·호로 다시 그렸습니다(아이콘 폰트·능력치 패널).
- 용어는 국내 정발·방영판 기준입니다(`translation/GUIDE.md`).

## 폰트
게임은 텍스트마다 글리프 번호를 쓰는 자체 16px 폰트를 씁니다. 원본 문자표가 없어 폰트 이미지를 OCR로 복원했고, 한글은 원본 획 두께에 가장 가까운 **나눔스퀘어네오 Regular 16px**로 새로 그렸습니다. 이미지 라벨은 나눔스퀘어네오 Bold를 썼습니다.

## 알려진 한계
- 스태프롤은 전용 폰트를 써서 원문(일본어)을 유지했습니다.
- 한자 한 글자 장식(호정 13대 번호 문장, 두루마리·메달의 十二·浦 등)과 타이틀 로고, 저작권 표기는 원본 그대로입니다.
- 원본 문자열 저장 공간이 고정돼 있어 일부 대사는 원문보다 간결하게 옮겼고, 좁은 이름 칸은 약칭을 썼습니다.
- 원문은 OCR로 복원한 것이라 드물게 오역이 있을 수 있습니다.
- PPSSPP에서 부팅·오프닝·서장 대사·튜토리얼·불러오기·메뉴·소울 피스·도움말·옵션 화면까지 확인했습니다. 전체 진행과 실기는 검증하지 않았습니다.

## 빌드
`python tools/build.py 출력.iso` — 번역 적용, 폰트·배지·이미지 재작성, cfc.dig 재압축, ISO 생성까지 한 번에 합니다. 원본 ISO와 `work/dig/`(`tools/unpack_all.py`로 해제), `work/blocks.json`, `work/gim_index.json`이 필요합니다. 포맷은 `TECHNICAL.md`에 있습니다.
